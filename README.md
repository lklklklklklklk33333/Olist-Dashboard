## Описание проекта
Этот проект представляет собой интерактивный BI-дашборд для бразильского маркетплейса Olist. Основная бизнес-задача — предоставить стейкхолдерам удобный инструмент для мониторинга ключевых показателей эффективности (KPI), таких как общая выручка, объем заказов, скорость доставки и географическое распределение спроса.

## ⚙️ Архитектура и подготовка данных (Data Engineering)
BI-инструмент — это только верхушка айсберга. Основная работа была проделана под капотом (см. код в файле `data_preparation.ipynb`).
Для построения дашборда была спроектирована единая витрина данных (Data Mart) на 112 650 строк. 

**Ключевые этапы трансформации (ETL):**
* **Сборка схемы "Звезда":** Объединение 5 таблиц: `orders`, `order_items`, `products`, `customers` и `geolocation`.
* **Очистка данных:** Фильтрация исключительно успешно доставленных заказов (`order_status == 'delivered'`).
* **Пространственная аналитика (Geo-spatial):** Устранение дубликатов в таблице геолокаций путем усреднения широты (`lat`) и долготы (`lng`) для каждого почтового индекса (zip code) перед джойном с таблицей клиентов.
* **Локализация:** Подтягивание справочника с английским переводом категорий товаров из `product_category_name_translation`.

## 📈 Структура дашборда

1. **Верхнеуровневые KPI:** Общая выручка (13.59M R$), количество заказов (98k+) и среднее время доставки (12.47 дней).
2. **Динамика во времени:** Линейный график корреляции выручки и количества заказов по месяцам.
3. **Анализ категорий и географии:** Горизонтальные бар-чарты для ранжирования топ-категорий и распределения выручки по штатам Бразилии.
4. **Гео-аналитика (Heatmap):** Детальная тепловая карта плотности заказов на карте страны.

Все элементы дашборда связаны: при выборе конкретной категории или временного промежутка, остальные графики и карта перестраиваются динамически.

## 💡 Ключевые бизнес-инсайты (Data Insights)
Анализ построенного дашборда позволяет сделать несколько важных выводов о состоянии бизнеса:

1. **Географическая концентрация выручки:** Абсолютное большинство заказов и основная доля выручки приходятся на юго-восточные штаты (в первую очередь `SP` — Сан-Паулу, `MG` и `RJ`). На тепловой карте эти регионы образуют плотные кластеры, в то время как северные регионы практически не охвачены.
2. **Локомотивы продаж:** Топ-3 категории (`health_beauty`, `watches_gifts`, `bed_bath_table`) генерируют непропорционально большую долю общей выручки. Фокус маркетинговых кампаний на этих категориях дает наибольший ROI.
3. **Зависимость логистики и спроса:** Наблюдается четкая корреляция между средним временем доставки и удержанием клиентов/объемом заказов. В штатах с быстрой доставкой объем продаж кратно выше.
